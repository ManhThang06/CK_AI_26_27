# Engine C và phần hỗ trợ bản đồ A

Giữ nguyên engine từ ZIP C; hướng và hành động là Enum; vị trí `(x,y)`.
Map: `1/2` tank, `A/B` base, `#` wall 3 HP, `.` nền.
Small giữ nguyên; medium/full bổ sung theo cùng format.
Chạy từ Vy_A: `python run.py unittest discover -s source/task2_tank/tests -v`.
Agent tìm kiếm và GUI do B/D ghép tiếp. Không dùng Battlefield của bản A cũ vào engine này.
Xem `docs/THAY_DOI.md` trước khi sửa terminal hoặc thứ tự cập nhật đạn.
